# JourJour — ваш помощник в путешествии

*[English version](README.md)*

**JourJour** — *journey journal* — приложение для Android, которое помогает спланировать
поездку и провести её. Интернет для работы не нужен, рекламы, аккаунтов и слежки нет, а
валюты, способы оплаты и категории расходов настраиваются под ваш способ путешествия.

---

## Что умеет

- **Учёт расходов в поездке.** Записи в разных валютах, фото чеков, координаты места,
  экспорт и импорт для обмена с внешними системами, отчётность и статистика по тратам с
  диаграммами.

- **Сверка остатков и оборотов по кошелькам.** Сколько в кошельке сейчас, что показал
  последний пересчёт и какой суммой банк закрыл операцию по карте.

- **Ведение чек-листов.** Что сделать до отъезда, по разделам, с копированием из прошлых
  поездок.

---

## Как собрать

**Понадобится** JDK 17 или новее и Android SDK с платформой 36. Остальное Gradle заберёт
сам.

```bash
git clone https://github.com/alex-plekhanov/jourjour.git
cd jourjour

./gradlew assembleDebug          # app/build/outputs/apk/debug/
./gradlew installDebug           # на подключённое устройство или эмулятор

./gradlew test                   # модульные тесты на JVM
./gradlew connectedAndroidTest   # инструментальные тесты, нужно устройство
```

`assembleRelease` соберёт **неподписанный** APK: в репозитории нет ни ключа, ни настроек
подписи — для подписанной сборки нужен ваш собственный ключ.

Приложение написано на Kotlin с Jetpack Compose, Room, Hilt и Navigation Compose. В
`DESIGN.md` описано, что приложение должно делать и почему код устроен именно так, —
прочитайте это, прежде чем что-то менять.
